# COMPORTAMIENTOS DE CIMA BOT

## Slash Commands
### No existe el comando
Si el comando no existe, este responde con un mensaje efimero diciendo que no esta disponible.
Mientras en consola se registra un redesplegamiento de los comandos

### Errores al ejecutar
Si el comando tira error, se responde con un mensaje diciendo que algo fallo.
Mientras en consola se registra el error especifico
